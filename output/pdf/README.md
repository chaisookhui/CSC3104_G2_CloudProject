# Which submission documents to use

Current documents describe the same final ledger: all 25 cases passed their
recorded local acceptance conditions, with 15 newly verified cases plus 10
complete final v9 cases independently re-audited and 321 audit checks passed.

- `GROUP02_INSTRUCTIONS.pdf` and `.md`: current 25-case deployment/testing
  instructions and final evidence scope. The examiner edition has 26 pages:
  Quick Start on page 2, demonstration route on page 3 and linked expected/result
  matrices on pages 23-24. See the [examiner-edition verification](../../docs/EXAMINER_GUIDE_VERIFICATION.md).
- `GROUP02_Test_Results_and_Distributed_Concepts_Report.pdf` and `.md`: current
  22-page results report, measurements, graphs and interpretation limits.
- `GROUP02_Combined_Test_Results.pdf`: the same current 22-page report followed
  by labelled historical source appendices (43 pages total).

`GROUP02_Complete_Testing_Handbook_Revised.pdf` and `.md` are archived 10 November
reference material. Their older 30-case catalogue and Experiments-screen
instructions do not describe the current application or final 25-case status.
Their original content is retained; do not submit that handbook as the current
testing guide.

The [evidence index](../../docs/VALIDATION_EVIDENCE.md) locates raw reviewer
packages. The [final submission verification](../../docs/FINAL_SUBMISSION_VERIFICATION.md)
records current document/package checks. Local acceptance is not a guarantee of
production reliability or the outcome of a new execution on another machine.
